## Ringkasan Proyek

- **Masalah:** Sulit memahami tren isu utama dari banyaknya berita politik daring.
- **Pendekatan:** Analisis topik berbasis data teks untuk mengelompokkan isu pemberitaan.
- **Insight Utama:** Isu politik membentuk topik dominan dan menunjukkan pola temporal.
- **Dampak:** Mendukung analisis media dan pemantauan isu publik berbasis data.
